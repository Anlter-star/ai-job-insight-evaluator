# v1.0.0

首个可复现作品版本，固定了从招聘信息采集、人工标注、结构化提取到模型评测和错误分析的完整链路。

## 主要内容

- 9 条开发数据、9 条调优数据和 15 条未见冻结测试数据。
- 透明关键词规则基线与 OpenAI 兼容的大模型提取器。
- Prompt v1-v3 的迭代记录和独立结果目录。
- 严格匹配、归一化匹配与原文依据检查三层评测。
- 页面顶部元数据和数据集级用工类型上下文进入模型输入。
- Streamlit 演示：在线解析、最终指标浏览、冻结数据校验。
- 35 项数据、提取器、评测器和演示辅助逻辑自动化测试。

## 最终测试结果

- 单值字段宏平均准确率：97.78%。
- 严格列表微平均 F1：22.22%。
- 归一化列表微平均 F1：24.69%。
- 潜在无原文支持项率：10.90%。
- 用工类型、地点、日薪、学历、到岗天数和实习期限：100%。

## 已知限制

- 列表字段对标签粒度和概念拆分方式敏感。
- 工具名称与硬技能仍可能发生字段归属混淆。
- 产品经理与大模型评测职责交叉时存在类别边界问题。
- 在线 Prompt v3 演示依赖用户自行配置的模型 API。
