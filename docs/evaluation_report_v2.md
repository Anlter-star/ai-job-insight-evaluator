# 首轮结构化提取评测报告（v2）

## 实验设置

- 数据集：9条公开实习岗位，产品经理、大模型评测、数据分析各3条。
- 标准答案：依据统一标注规范人工制作。
- 对比方法：关键词规则基线与 DeepSeek Flash（Prompt v1）。
- 单值字段：岗位类别、用工类型、地点、学历、在校状态、毕业年份、每周到岗天数、实习月份。
- 列表字段：必需硬技能、必需工具、优先硬技能、优先经历。

## 核心结果

| 方法 | 单值字段准确率 | 严格技能 Precision | 严格技能 Recall | 严格技能 F1 | 归一化技能 Precision | 归一化技能 Recall | 归一化技能 F1 | 潜在无依据率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 关键词规则 v1 | 79.17% | 96.83% | 76.25% | 85.31% | 96.83% | 76.25% | 85.31% | 0.00% |
| DeepSeek Flash + Prompt v1 | 75.00% | 37.14% | 48.75% | 42.16% | 62.26% | 82.50% | 70.97% | 0.00% |

## 关键发现

### 1. 严格匹配显著低估了大模型的语义正确性

DeepSeek 的技能 F1 从严格匹配的42.16%提升至归一化后的70.97%。26个预测项通过人工审核的同义映射得到纠正，例如“开发AI Agent”与“AI Agent开发”。这说明字符串完全匹配适合做可复现下界，但不适合单独衡量开放式抽取结果。

### 2. 第一版“幻觉率”不能直接解释为模型捏造

第一版把所有标准答案之外的标签都计为幻觉，得到62.86%。第二版检查原始职位文本后发现，40个额外项有直接原文依据；经同义映射和原文依据检查后，没有项目进入“潜在无依据”队列。因此，第一版指标更准确的名称应为“严格额外项率”。

潜在无依据率为0%并不代表所有预测都正确：预测可能放错字段、拆分粒度不同，或者岗位类别判断错误。它只表示当前预测项均能在原文或人工审核映射中找到依据。

### 3. 规则方法精度高，但当前结果不是泛化能力证明

规则词典依据首批样本设计，因此在同一批9条数据上具有明显优势。规则方法归一化前后结果相同，技能 F1 为85.31%，主要优势来自标准标签词典；需要使用新增、未参与词典设计的岗位作为测试集，才能公平比较泛化能力。

### 4. 输入数据缺失限制了两种方法

部分岗位的每周到岗天数、实习期限和学历只出现在招聘页面顶部，没有进入职位正文。DeepSeek 的每周到岗天数和实习期限准确率均为33.33%。这属于输入数据覆盖问题，不能仅通过优化提示词解决。

### 5. 大模型仍存在任务理解与字段归属问题

DeepSeek 将2条相邻岗位判断为产品经理而非大模型评测；部分“优先经历”被放入“优先硬技能”，复合要求的拆分粒度也与人工标准不一致。下一轮 Prompt v2 应重点加入字段边界示例和岗位分类判定规则。

## 结论与下一步

当前实验表明：规则方法在封闭词典和小样本内精度更高；大模型能够覆盖更多语义表达，但需要明确的标签体系、归一化评测与字段边界约束。下一阶段应新增未见岗位作为测试集，并在不修改标准答案的前提下比较 Prompt v1 与 Prompt v2。
