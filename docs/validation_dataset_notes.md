# 第一批冻结验证集说明

版本：v1.0  
采集日期：2026-10-18  
数据文件：`data/validation/validation_dataset.jsonl`

## 数据构成

本批验证集共9条岗位，和现有9条开发集保持同样的类别分布：

| 类别 | 数量 | 岗位编号 |
| --- | ---: | --- |
| 产品经理 | 3 | `VAL_PM_001`～`VAL_PM_003` |
| 大模型评测 | 3 | `VAL_LLMEVAL_001`～`VAL_LLMEVAL_003` |
| 数据分析 | 3 | `VAL_DA_001`～`VAL_DA_003` |

这批数据专门用于检验第一版规则提取器和大模型提取器在未见岗位上的泛化能力。不得在首轮验证前用它修改规则、提示词或归一化别名。

## 标注处理

- 页面顶部的地点、薪资、学历、到岗天数和期限作为结构化元数据录入。
- 原标题在截图中被省略号截断时，不猜测括号中的完整内容，并写入 `title_truncated`。
- 页面顶部和正文冲突时，按标注规范采用顶部结构化值，同时在 `ambiguities` 保存另一取值和原因。
- 本批数据的采集范围已确认仅包含公开实习岗位，因此9条记录的 `employment_type` 统一标为`实习`。标题未明示的4条记录使用数据集采集范围作为证据，而不是根据日薪或页面样式推断。
- SenseTime算法岗作为“大模型评测”的相邻岗位保留，并用 `role_mismatch` 标记，检验分类边界。
- 物理命题专家页面顶部学历为博士、正文为硕士及以上，标准值按现有规范采用博士并保留冲突。

## 首轮验证顺序

1. 锁定当前提交的开发集、规则、提示词和别名表版本。
2. 对验证集运行规则提取器并保存独立预测文件。
3. 使用相同模型配置运行大模型提取器，保存原始预测。
4. 用评测器v2分别生成严格匹配、归一化匹配和证据检查结果。
5. 首轮结果归档后再做误差分析；任何后续改动必须产生新的版本号，不能覆盖首轮盲测结果。

## 后续调优状态

首轮盲测已经完成并归档。此后该文件继续保留原路径和 `validation` split 标记以兼容既有命令，但从 Prompt v2/v3 开始已作为已见的调优集使用，不再代表独立未见测试集。最终泛化结论必须另建新的冻结测试集得出。

Prompt v3 为每条记录补充 `input.dataset_context.employment_type=实习`，并收紧在校生判断、岗位分类、必需/加分字段边界和技能标签粒度。该上下文来自已经确认的采集范围，不从标准答案反向生成。
