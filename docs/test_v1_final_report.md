三个严格计分错误：

1. `TEST_PM_004`：标准类别为“产品经理”，模型判为“大模型评测”。该岗位标题是通用Agent数据产品经理，但职责高度集中于自动化评测、归因和数据生产，属于真实边界样本。

归一化主要改善必需硬技能：F1由26.09%升至31.30%；其他三个字段未因现有别名表得到额外提升。典型误差包括：

- 合并概念被拆分，例如“神策、TA、友盟或GA”被输出成四个工具。
- 标准答案使用抽象标签，模型保留原文措辞，例如“产品文档”与“撰写产品文档”。
- 工具被放进硬技能字段，例如SQL、Python或Excel。
- 加分经历被拆成多个独立经历，导致严格精确率下降。

## 结论

Prompt v3在未见冻结数据上保持了稳定的结构化单值抽取能力，尤其是此前重点修复的用工类型、地点、薪资、学历、到岗天数和实习期限全部达到100%。列表字段相较规则基线有显著召回提升，但仍受标签粒度、字段归属和精确匹配方式影响。

本轮属于最终测试，不再使用这些15条数据继续调优。若开启下一轮研发，应另建新的开发/验证数据，并保留本测试集及其校验值作为不可变回归基准。
